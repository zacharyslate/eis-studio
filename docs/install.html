Install EIS Studio

One command installs EIS Studio together with its own private copy of Python. You don't need Python, administrator rights or any other software. Besides the app's own folder, the installer only adds a shortcut and makes the eis-studio command available in new terminal windows.

  1. Open PowerShell

    Click Start, type PowerShell and open Windows PowerShell. A normal window is fine; you don't need "Run as administrator".

  2. Paste this command and press Enter

    powershell -ExecutionPolicy ByPass -c "irm https://zacharyslate.github.io/eis-studio/install.ps1 | iex"

    The first install downloads the scientific libraries and takes a few minutes, needing about 1 GB of free disk space.

  3. Start EIS Studio

    Double-click EIS Studio on your Desktop or in the Start Menu. A small window opens, then the app appears in your web browser. Keep the small window open while you work, and close it to quit.

  1. Open Terminal

    Press ⌘ + Space, type Terminal and press Enter.

  2. Paste this command and press Return

    curl -LsSf https://zacharyslate.github.io/eis-studio/install.sh | sh

    The first install takes a few minutes and needs about 1 GB of free disk space. It works on Apple silicon and Intel Macs, including older macOS versions: it picks library builds made for your system instead of compiling anything.

  3. Start EIS Studio

    Open EIS Studio from Launchpad, Spotlight, the Applications folder in your home folder, or the shortcut on your Desktop. A Terminal window opens, then the app appears in your web browser. Keep the Terminal window open while you work, and close it to quit. You can keep EIS Studio in the Dock like any other app.

  1. Open a terminal

    Use your desktop's terminal application. curl or wget must be available; it is on almost all distributions.

  2. Run the installer

    curl -LsSf https://zacharyslate.github.io/eis-studio/install.sh | sh

    The first install takes a few minutes and needs about 1 GB of free disk space.

  3. Start EIS Studio

    Choose EIS Studio from your applications menu, or type eis-studio in a new terminal. The app opens in your browser at http://localhost:8501.

After installing

Update to the latest version

Run the same install command again. It replaces the installed version with the current one.

Uninstall

uv tool uninstall eis-studio

Then delete the shortcuts: EIS Studio on the Desktop and in the Start Menu (Windows), EIS Studio.app in the Applications folder of your home folder and its Desktop link (macOS), or ~/.local/share/applications/eis-studio.desktop (Linux). The installer also put uv, the small tool that manages the installation, in your user folder. Remove it as described in uv's uninstall instructions if you don't use it for anything else.

What the installer does

It installs uv if it is missing. uv then downloads Python 3.12 and EIS Studio's libraries into a separate folder in your user account and creates the eis-studio command and a shortcut. You can read the scripts before running them: install.ps1 for Windows and install.sh for macOS and Linux.

If something goes wrong

“eis-studio” is not recognised, or “command not found”

Close the terminal and open a new one; the installer adds the command's folder to your PATH, and open windows don't see the change. The desktop shortcut works either way.

The browser didn't open

Open http://localhost:8501 yourself. If that port was busy, the terminal window shows the address it used instead (8502, 8503, …).

The download fails on a university or company network

Networks that inspect HTTPS traffic can block the download. Try from another network, or ask IT to allow astral.sh, github.com, pypi.org and files.pythonhosted.org.

Antivirus quarantines eis-studio.exe (Windows)

The launcher is a small, unsigned program created on your own computer during installation, and some antivirus products flag those. Restore it, or allow the folder %USERPROFILE%\.local\bin.

I already use Python and prefer pip

Install into any environment with Python 3.10 or newer, then start it with eis-studio:

pip install "eis-studio @ https://github.com/zacharyslate/eis-studio/archive/refs/heads/main.zip"
Something else

Open an issue on GitHub with your operating system and the text shown in the terminal window.
